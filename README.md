# Ejercicios básicos de Python 🐍

Esto es una pequeña colección de scripts y notebooks con ejercicios sencillos de Python, 
de cosas que he hecho con el tiempo, pensados para practicar la sintaxis básica y tener un pequeño portfolio técnico.

## Contenido del repositorio

Cada archivo `.py` o `.ipynb` contiene ejemplos cortos centrados en un concepto concreto:

- `intro_python`  
  Primeros pasos con Python: impresión por pantalla, tipos básicos y comentarios.

- `print`  
  Ejemplos de uso de `print()` y diferentes formas de mostrar información por consola.

- `texto_tabulado`  
  Formateo de texto, uso de saltos de línea, tabulaciones y cadenas multilínea.

- `crear_listas` / `listas_tuplas_sets`  
  Creación y manipulación de listas, tuplas y conjuntos: acceso por índice, operaciones básicas y recorrido con bucles.

- `def_preorden`  
  Definición y uso de funciones (`def`), orden de parámetros y ejemplos de reutilización de código.

- `if_elif_else`, `if_mensaje`, `if_verdadero_o_falso`  
  Condicionales en Python con `if`, `elif` y `else`: evaluación de expresiones lógicas y diferentes flujos según la condición.

- `input_leer`  
  Lectura de datos por teclado con `input()`, conversión de tipos y validaciones sencillas.

- `peliculas`  
  Ejercicios de manejo de listas y estructuras de datos usando ejemplos de películas (búsqueda, filtrado, etc.).

- `turtle`  
  Ejemplos usando el módulo `turtle` para dibujar en pantalla y practicar coordenadas y bucles.

- `presentacion`  
  Script de presentación/introducción, por ejemplo para mostrar datos personales o resumen del proyecto.

- `uso_basico`  
  Ejemplos generales de uso básico de Python que no encajan en una categoría concreta.

- Notebooks `.ipynb`  
  Versiones interactivas de algunos ejercicios, pensadas para ejecutarse en Jupyter Notebook o JupyterLab.

> Los nombres de los archivos pueden variar ligeramente, pero la idea es que cada uno se centre en un concepto básico de Python.

## Requisitos

Para ejecutar los scripts necesitas:

- Python 3.8 o superior instalado en tu sistema.
- Opcional:  
  - Un editor de código (VS Code, Spyder, PyCharm, el que más te guste, hay un montón de opciones!).  
  - Jupyter Notebook / JupyterLab para los archivos `.ipynb`.

## Cómo ejecutar los ejercicios

1. Clona este repositorio:

   ```bash
   git clone https://github.com/NoeliaTJ/MainNoe.git
   cd MainNoe
   ```

2. Ejecuta cualquier script de Python:

   ```bash
   python nombre_del_script.py
   ```

   Por ejemplo:

   ```bash
   python intro_python.py
   python if_elif_else.py
   python crear_listas.py
   ```

3. Para abrir un notebook (`.ipynb`):

   ```bash
   jupyter notebook
   ```

   Luego selecciona el archivo desde la interfaz web.

# Turtle.py 🐢

Este repositorio contiene un script en Python que utiliza el módulo `turtle` para dibujar en pantalla.  
Está pensado como práctica de programación básica en Python y uso de gráficos sencillos.

## Requisitos

- Python 3 instalado en tu sistema.
- Módulo `turtle` (viene incluido en la instalación estándar de Python en la mayoría de sistemas).

## Cómo ejecutar el programa

1. Clona el repositorio:

   ```bash
   git clone https://github.com/NoeliaTJ/MainNoe.git
   cd MainNoe
   ```

2. Ejecuta el script:

   ```bash
   python3 Turtle.py
   ```

   En algunos sistemas puede ser:

   ```bash
   python Turtle.py
   ```

## Descripción del script

El archivo `Turtle.py`:

- Crea una ventana gráfica.
- Utiliza una “tortuga” (es un triángulo) para dibujar formas en pantalla (líneas, figuras, etc.).
- Es ideal para practicar:
  - Coordenadas.
  - Bucles.
  - Funciones en Python.
  - Lógica de dibujo paso a paso.

## Estructura del repositorio

- `Turtle.py` — Script principal con el código de dibujo usando `turtle`.
